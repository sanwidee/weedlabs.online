Cara Pakai

3 langkah simpel untuk mulai.

01
Download template pilihanmu
Klik tombol Download Excel di atas. File .xlsx akan langsung tersimpan di komputer kamu.
02
Isi sel berwarna biru
Sel biru adalah input — isi dengan data kamu. Sel hitam adalah formula otomatis, jangan dihapus. Baca sheet "Cara Pakai" kalau bingung.
03
Lihat insight-mu langsung
Dashboard otomatis terupdate saat kamu mengisi data. Pakai insight-nya untuk keputusan keuangan yang lebih baik.
