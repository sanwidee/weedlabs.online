Changelog

Everything that ships, in order. Local-first stays the default — cloud is always opt-in.

0.2.0 — Cloud boosters

29 Aug 2026
  • NewElevenLabs Scribe engine — pick Cloud · ElevenLabs Scribe in the Model menu for dramatically better Bahasa Indonesia transcription than the local small model. Bring your own key in ~/.typeflow.json; falls back to local automatically if the network or key is missing.
  • New"AI Prompt (EN)" tone — dictate a ramble in Indonesian, English, or a mix, and get back one structured English prompt ready to paste into an AI tool. It resolves mid-sentence corrections ("eh salah, maksudnya…") and preserves product names, paths and numbers exactly.
  • NewCloud post-processing — set "postprocess": "cloud" to route all tone presets through a frontier model via OpenRouter instead of the local Qwen. The prompt tone always uses cloud when a key is present.
  • FixSanity window widened for structured outputs so legitimate expansions (prompt mode) aren't rejected as hallucinations.
  • Everything fails soft: no key, no network, or a bad response returns your untouched transcript — you never paste garbage.

0.1.0 — First release

Aug 2026
  • Global hotkey voice typing for macOS (⌘ \, rebindable) — record from any app, transcript lands on the clipboard.
  • Local Whisper via faster-whisper: small / medium / large-v3-turbo / large-v3, all offline after first download.
  • English & Bahasa Indonesia in the UI; code-switching works.
  • Optional on-device polishing (Qwen 2.5): fluent, friendly, professional, translate ID↔EN, custom prompt.
  • Menu-bar app with live level meter, mic picker, mic test, floating overlay.
  • MIT licensed, no telemetry, no account.
